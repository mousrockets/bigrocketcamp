# Direct depuis un onglet PC (à tester)

`/direct` lit uniquement `ws://localhost:49124/`, l’API locale officielle de Rocket League. Le jeu doit avoir `PacketSendRate=10`, `Port=0`, `WebPort=49124` sous `[TAGame.MatchStatsExporter_TA]` dans son fichier de configuration Stats API, avant lancement. Le navigateur et le jeu peuvent refuser la connexion : ce mode reste à valider avec une vraie partie sur le PC de jeu, notamment l’Origin HTTPS, l’autorisation Local Network Access, les forfaits et les départs immédiats. Ne jamais conseiller de désactiver la sécurité du navigateur pour contourner un refus.

L’utilisateur active explicitement le direct sur son appareil et garde cet onglet ouvert pendant le jeu. Aucun exécutable supplémentaire, secret de collecte, mot de passe, commande de jeu ou session PsyNet n’est utilisé par l’onglet. Le flux accepte les enveloppes concaténées/fragmentées et `Data` objet ou JSON encodé, avec limites de taille. Une partie doit être observée dès `MatchCreated`/`MatchInitialized` ; une connexion en cours de partie attend la suivante. `ReplayCreated` bloque les replays d’historique. Les replays de buts ne bloquent pas les matchs suivants.

Après `MatchEnded`, deux mises à jour finales identiques sont requises avec `bHasWinner`, `bReplay=false`, un gagnant cohérent, les identités et les effectifs complets d’une playlist publique connue. Aucun dernier tick avant la fin n’est présenté comme un tableau final. Un participant disparu, un bot sans identifiant ou un tableau incomplet laisse le match à la collecte Epic différée. Les playlists privées, entraînement, bots et inconnues sont exclues. La date est celle du début observé en heure de Paris, comme le regroupement par début de match de l’historique Epic. Les données du navigateur restent déclaratives ; Epic est prioritaire lorsqu’il revient.

`POST /api/live` exige la connexion ChatGPT, la même origine et un tableau contenant le compte Epic joueur autorisé par cet utilisateur. L’identité liée fixe son nom dans le club. Le serveur ne lit que les identifiants de liaisons nécessaires, jamais leurs jetons. Les observations et rapports complets utilisent le chemin de réconciliation existant. Le navigateur conserve au plus 20 matchs en attente pendant une coupure ; il retire un envoi seulement après un accusé de réception valide du serveur. Les répétitions, plusieurs onglets et une confirmation Epic ne créent pas de partie supplémentaire.

L’affichage existant relit les données reçues toutes les trois secondes sur les autres appareils. Le direct local s’arrête lorsque son PC ou son onglet s’arrête. Epic et les tâches serveur continuent. Les joueurs PS5 présents dans le match du PC sont inclus ; aucun direct PS5 solo n’est vérifié.

Sources : [Stats API officielle](https://www.rocketleague.com/developer/stats-api), [notes v2.72](https://www.rocketleague.com/news/rocket-league-patch-notes-v2-72), client communautaire Rockpload révision `3b9057cd762fdef0a737b25ed13a1074f491ee2e` (enveloppe et transport WebSocket). Les tests utilisent des données synthétiques et ne remplacent pas un essai sur le jeu.
